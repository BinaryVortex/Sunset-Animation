# Sunset Animation

A beautiful, interactive sunset animation created using HTML, CSS, and JavaScript. This project features a scroll-triggered animation that transitions from day to night, showcasing various elements like moving clouds, flying birds, bats emerging at dusk, and stars appearing in the night sky.

## Demo

View the live demo: [https://binaryvortex.github.io/Sunset-Animation/](https://binaryvortex.github.io/Sunset-Animation/)

## Features

- **Scroll-Based Animation**: The scene changes as you scroll, simulating the passage of time from sunrise to nightfall.
- **Dynamic Elements**:
  - Sun setting with color transitions
  - Moving clouds
  - Flying bird animation
  - Bats appearing and flapping
  - Stars twinkling in the night
  - Falling star effect
- **Fullscreen Mode**: Click the "Go Fullscreen" button for an immersive experience.
- **Responsive Design**: Optimized for various screen sizes.

## Technologies Used

- **HTML5**: Structure of the animation
- **CSS3**: Styling and gradients
- **JavaScript**: Animation logic
- **GSAP (GreenSock Animation Platform)**: For smooth, professional animations and ScrollTrigger for scroll-based interactions

## Installation and Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/BinaryVortex/Sunset-Animation.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Sunset-Animation
   ```

3. Open `index.html` in your web browser to view the animation.

4. Scroll down to trigger the animations, or use the fullscreen button for a better experience.
